Top 4 Exam Tips (Where Marks Are Gained & Lost):
  • Write PC = 302 explicitly! Always show 300 + 2 = 302 before computing Relative mode (302 + 400 = 702).
  • Immediate mode distinction: Clearly write BOTH Operand = 400 and EA = 301 so any marking scheme awards full marks.
  • Pure theory 15m (Jun 2025 Q26): Include all 8 modes above + 1 assembly example each + a summary table at the end.
  • Instruction format MCQs: \(\text{Opcode bits} = W - (\lceil\log_2 R\rceil + \lceil\log_2 M\rceil + \log_2 \text{RAM})\). For 12 regs (4b), 6 modes (3b), 64K×32 RAM (16b): 32 - 23 = 9 bits.
Quick 0 / 1 / 2 / 3-Address Cheat (X = (A+B)*(C+D))
  • 3-Addr: ADD R1,A,B; ADD R2,C,D; MUL X,R1,R2
  • 2-Addr: MOV R1,A; ADD R1,B; MOV R2,C; ADD R2,D; MUL R1,R2; MOV X,R1
  • 1-Addr (AC): LOAD A; ADD B; STORE T; LOAD C; ADD D; MUL T; STORE X
  • 0-Addr (Stack): PUSH A; PUSH B; ADD; PUSH C; PUSH D; ADD; MUL; POP X

Unit 1 (CO1) Visual Revision — 12 Marks (8/8 Papers)

Everything needed for Q21 (8m) and Part A Q1–Q4 (4m).

Easiest Unit · Guaranteed Marks
1. Base Conversions (With Fractions!)
  • Integer part (÷ base): Divide by 2, 8, or 16; read remainders bottom → top.
  • Fractional part (× base): Multiply fraction by 2, 8, or 16; take integer digits top → bottom (4–6 digits).
  • Fast Grouping: Binary ↔ Octal = 3 bits per digit; Binary ↔ Hex = 4 bits per digit (pad outer edges with 0).
  • Example (Jun 25 Q21a): \(105.15_{10} = 1101001.00100110_2 = 151.1146_8 = 69.2666_{16}\).
2. 1's & 2's Complement Subtraction (A - B)
  • First: Pad A and B to the exact same bit width!
  • 2's Comp (A + (~B + 1)):
    Carry = 1 → discard carry (answer +).
    Carry = 0 → negative (take 2's comp & put -).
  • 1's Comp (A + ~B):
    Carry = 1 → add End-Around Carry (EAC) to LSB (+).
    Carry = 0 → negative (flip bits & put -).
  • Gray Code (Part A): Copy MSB, XOR adjacent bits (1010 → 1111, 11011 → 10110).

Draw Diagrams = Half the Marks

1. 5-Stage Instruction Pipeline Space-Time Diagram (May 2026 Q24a)

Stages: IF → ID → EX → MEM → WB Cycles = \(k + (n - 1)\) Latency stays ~same · Throughput increases!

2. The 3 Pipeline Hazards & How to Overcome Them (May 2026 Q24b)

1. Structural Hazard Cause: Two instructions need the same hardware at the same time (e.g., 1 memory port for both IF & MEM).
Fix: Separate I-Cache & D-Cache, or insert 1 stall cycle.
2. Data Hazard (Most Asked!) Cause: Operand isn't ready yet.
• RAW (Read After Write — true dep)
• WAR (Write After Read)
• WAW (Write After Write)
Example: ADD R1,R2,R3 → SUB R4,R1,R5
Fixes: (1) Operand Forwarding (EX→EX bypass), (2) Stalls / NOPs, (3) Register Renaming (fixes WAR/WAW), (4) Compiler scheduling.
3. Control (Instruction) Hazard Cause: Branch/jump changes PC after fetch has already started.
Fixes: (1) Branch Prediction (Static or Dynamic 1-bit / 2-bit), (2) Delayed Branching, (3) Flush pipeline.
Operand Forwarding (Bypassing) Visual Path: Instead of waiting for ADD R1,R2,R3 to finish WB, hardware forwards ALU output from EX/MEM buffer straight back into SUB R4,R1,R5's EX ALU input (0 stall cycles!).
Control Unit Quick Backup (MCQs + Diagrams):
• WMFC: Wait for Memory Function Completed · RUN: increments step counter · End: resets step counter to T1.
• Control Store: Special memory holding microroutines in MCU. · Hardwired CU: Faster, less flexible, cannot handle complex CISC.

2. ARM Processor (Nov 24 / Jun 25 / Nov 25 / May 26)
  • Architecture: 32-bit RISC, Hardwired control unit, Load/Store model (ALU works ONLY on registers; Load/Store frequency ~40%).
  • 2 Instruction Sets: 32-bit ARM state & 16-bit Thumb state (switches via BX; ~35% smaller code).
  • 7 Operating Modes: User, FIQ, IRQ, Supervisor, Abort, Undefined, System.
  • Load/Store Instructions:
    • Single: LDR R0, [R1] / STR R0, [R1] (LDRB, LDRH)
    • Pre-indexed: LDR R0, [R1, #4]! (updates R1 first)
    • Post-indexed: LDR R0, [R1], #4 (reads, then updates R1)
    • Block transfer: LDMIA / STMDB (fast stack/register save).
3. Cache Coherence & MESI Protocol (4/8 papers)
  • Problem: Multiple CPU caches hold copies of the same shared memory address; when CPU1 writes, CPU2 sees stale data.
  • Solutions: Write-Invalidate / Write-Update snooping protocols & Directory-based protocols.
  • MESI 4 States:
    • M (Modified): Dirty (differs from RAM), only in this cache.
    • E (Exclusive): Clean (matches RAM), only in this cache.
    • S (Shared): Clean, present in 2+ caches.
    • I (Invalid): Stale / unusable — must fetch on read.
  • MCQ Hooks: Hit rate = hits / total accesses; Write miss = block missing in cache on write.
